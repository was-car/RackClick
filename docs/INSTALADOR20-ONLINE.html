Español · instalación y datos

  1. Prepara un servidor nuevo con cuenta administradora. Conserva tus snapshots e instalaciones existentes; el asistente rechaza controladores de dominio y equipos con RackClick instalado.
  2. Descarga RackClick-Windows-Online-20.zip y su SHA256 desde la Release pública de GitHub, sin iniciar sesión. Copia el ZIP a C:\RackClick_Instalar20. Inicio → PowerShell → botón derecho → Ejecutar como administrador. Comprueba el hash con el valor externo de la Release:
Get-FileHash -Algorithm SHA256 -LiteralPath 'C:\RackClick_Instalar20\RackClick-Windows-Online-20.zip'
Expand-Archive -LiteralPath 'C:\RackClick_Instalar20\RackClick-Windows-Online-20.zip' -DestinationPath 'C:\RackClick_Instalar20\Extraido20'
  1. Abre Extraido20\RackClick-Windows-Online-20 y ejecuta INICIAR-RACKCLICK.cmd como administrador. Confirma ADQUIRIR para las descargas oficiales fijadas, aproximadamente 700 MB. Se comprueban sus tamaños y hashes antes de utilizarlas.
  2. El montador Python es temporal. Del archivo SDK 10.0.401 se selecciona sólo el runtime 10.0.12; PostgreSQL 17.11-4 y VC++ mantienen sus pins. No hace falta instalar manualmente SDK, Node ni Python ni compilar RackClick. El ZIP de transporte no incluye estos runtimes.
  3. En el asistente elige New. Revisa IP, nombre de navegador, subred, HTTPS 5443/PG 55441, Systemhaus, usuario inicial y cuenta de servicio estándar. Se generan contraseña, claves y certificados nuevos. El asistente no cambia la IP/DNS de Windows. Consulta la contraseña en Acceso privado del panel instalado.
  4. Abre la URL HTTPS indicada. Comprueba catálogo, racks y Tu cuenta/MFA. Sigue vigente la gracia de 45 días y la exención para administradores globales del Systemhaus; cada persona inscribe su propio autenticador.
  5. En Administración → Datos y copias de inventario, marca la confirmación y pulsa Cargar 50 clientes. Sólo admite inventario vacío. El resultado confirmado contiene 50 clientes, 66 sitios, 88 edificios, 226 salas, 180 racks, 1563 equipos, 2869 grupos, 20665 puertos y 2207 conexiones. Recarga y vuelve a iniciar sesión para comprobar persistencia. Los nombres fijos EN/DE/ES se conservan al cambiar el idioma.
  6. Desde el mismo panel descarga una Copia de inventario. El archivo contiene los clientes y su inventario; conserva UUID y metadatos. No incluye usuarios, permisos, contraseñas, sesiones, MFA ni plantillas privadas o compartidas. Guárdalo de forma privada si contiene datos de tu trabajo.
  7. Para restaurar esa copia, usa otro inventario vacío: selecciona el archivo, revisa la vista previa y confirma la restauración. No sobrescribe ni fusiona inventario existente. Las cuentas y MFA del destino se conservan. La copia no sustituye el backup PostgreSQL/Windows; las guardias de Restore48 siguen vigentes.
  8. Si se pierde la respuesta de una importación, conserva la intención y consulta su resultado en el panel antes de continuar. No repitas automáticamente la carga ni borres datos para volver a intentarlo.
  9. Crea también el backup operativo desde el panel de instalación. Reinicia Windows manualmente y abre el acceso RackClick-VERIFICAR-20 → Verificar instalación. Comprueba servicio, HTTPS y los 50 clientes; conserva los informes y tu resultado manual. La aceptación instalada corresponde al ensayo de Wascar.

English · installation and inventory

  1. Use a new Windows Server 2025 x64 Desktop Experience application server with administrator access and HTTPS Internet. Preserve existing installations and snapshots. Domain controllers and existing RackClick installations are rejected.
  2. Download RackClick-Windows-Online-20.zip and its external SHA256 from the public GitHub Release into C:\RackClick_Instalar20. No sign-in is required. Start → PowerShell → right-click → Run as administrator. Verify the hash and extract to the new Extraido20 folder using the commands above. Run INICIAR-RACKCLICK.cmd as administrator.
  3. Confirm direct official downloads, approximately 700 MB. Exact lengths and digests are verified. Python is a temporary assembler; the SDK 10.0.401 archive supplies only runtime 10.0.12. PostgreSQL 17.11-4 and VC++ keep their pinned versions. The transport ZIP does not redistribute these runtimes; manual SDK, Node or Python installation and compilation are unnecessary.
  4. Select New. Review the browser hostname, address, subnet, HTTPS 5443/PG 55441, Systemhaus, initial user and standard service account. Fresh credentials, certificates and keys are generated; Windows IP/DNS are unchanged. Read the private password under Acceso privado in the installed panel.
  5. Open the HTTPS URL. Check the catalog, racks and your account/MFA. The 45-day policy and global Systemhaus administrator exemption remain. Each person enrols their own authenticator.
  6. Open Administration → Data and inventory copies, select the confirmation and click Load 50 customers. The destination inventory must be empty. A committed result contains 50 customers, 66 sites, 88 buildings, 226 rooms, 180 racks, 1563 devices, 2869 groups, 20665 ports and 2207 connections. Reload and sign in again to verify persistence. Company names keep their original EN/DE/ES text when the interface language changes.
  7. Download an Inventory copy from that panel. It preserves customer inventory, UUIDs and metadata. It excludes users, permissions, credentials, sessions, MFA and private/shared templates. Keep work data private.
  8. To restore, use another empty inventory: choose the file, review the preview and confirm. Existing inventory cannot be overwritten or merged. Destination accounts and MFA are preserved. This file does not replace PostgreSQL/Windows recovery; Restore48 guards remain.
  9. If an import response is lost, keep the pending intention and query its result in the panel. Do not retry automatically or remove data for another attempt.
  10. Also create the operational backup in the installation panel. Restart Windows manually, then open RackClick-VERIFICAR-20 → Verificar instalación. Check the service, HTTPS and all 50 customers. Preserve both automatic and manual results. Installed acceptance remains with Wascar.

DATOS-DEMO50\VER-50-CLIENTES.html is an offline synthetic-data viewer. Load the data through the web panel in this edition.

Deutsch · Installation und Inventardaten

  1. Neuen Windows Server 2025 x64 mit Desktopdarstellung, Administratorkonto und HTTPS-Internetzugang vorbereiten. Bestehende Installationen und Snapshots erhalten. Domänencontroller und vorhandene RackClick-Installationen werden abgelehnt.
  2. RackClick-Windows-Online-20.zip und die externe SHA256 aus dem öffentlichen GitHub-Release ohne Anmeldung nach C:\RackClick_Instalar20 herunterladen. Start → PowerShell → Rechtsklick → Als Administrator ausführen. Hash prüfen und wie oben in den neuen Ordner Extraido20 entpacken. INICIAR-RACKCLICK.cmd als Administrator starten.
  3. Direkte offizielle Downloads bestätigen, ungefähr 700 MB. Größe und Hash werden vor Verwendung geprüft. Python dient nur als temporärer Assembler; aus dem SDK-Archiv 10.0.401 wird ausschließlich Runtime 10.0.12 entnommen. PostgreSQL 17.11-4 und VC++ behalten ihre festen Versionen. Diese Runtimes sind nicht im Transport-ZIP enthalten. SDK, Node oder Python müssen nicht manuell installiert werden; RackClick wird nicht kompiliert.
  4. New wählen. Browsername, Adresse, Subnetz, HTTPS 5443/PG 55441, Systemhaus, ersten Benutzer und Standarddienstkonto prüfen. Neue Zugangsdaten, Zertifikate und Schlüssel werden erzeugt. Windows-IP/DNS bleiben erhalten. Das neue Passwort steht unter Acceso privado im Installationspanel.
  5. HTTPS-URL öffnen, Katalog, Racks und eigenes Konto/MFA prüfen. Die 45-Tage-Frist und Ausnahme für globale Systemhausadministratoren gelten weiterhin. Jede Person registriert ihren eigenen Authenticator.
  6. Administration → Daten und Inventarkopien öffnen, Bestätigung auswählen und 50 Kunden laden anklicken. Das Inventar muss leer sein. Das bestätigte Ergebnis enthält 50 Kunden, 66 Standorte, 88 Gebäude, 226 Räume, 180 Racks, 1563 Geräte, 2869 Gruppen, 20665 Ports und 2207 Verbindungen. Seite neu laden und erneut anmelden, um die Persistenz zu prüfen. Firmennamen behalten ihren ursprünglichen EN/DE/ES-Text beim Sprachwechsel.
  7. Im selben Panel eine Inventarkopie herunterladen. Kundeninventar, UUIDs und Metadaten bleiben erhalten. Benutzer, Berechtigungen, Zugangsdaten, Sitzungen, MFA und private/geteilte Vorlagen sind ausgeschlossen. Arbeitsdaten vertraulich aufbewahren.
  8. Zur Wiederherstellung ein anderes leeres Inventar verwenden: Datei wählen, Vorschau prüfen und bestätigen. Bestehendes Inventar wird weder überschrieben noch zusammengeführt. Konten und MFA des Ziels bleiben erhalten. Die Datei ersetzt keine PostgreSQL-/Windows-Wiederherstellung; Restore48 bleibt geschützt.
  9. Bei verlorener Importantwort die gespeicherte Absicht erhalten und das Ergebnis im Panel abfragen. Nicht automatisch wiederholen oder Daten für einen neuen Versuch löschen.
  10. Zusätzlich die Betriebssicherung im Installationspanel erstellen. Windows manuell neu starten und RackClick-VERIFICAR-20 → Verificar instalación öffnen. Dienst, HTTPS und alle 50 Kunden prüfen. Automatische und manuelle Ergebnisse aufbewahren. Die installierte Abnahme erfolgt durch Wascar.

DATOS-DEMO50\VER-50-CLIENTES.html zeigt die synthetischen Dateien offline. In dieser Ausgabe werden die Daten über das Webpanel geladen.

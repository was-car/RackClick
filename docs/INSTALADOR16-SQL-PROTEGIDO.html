01 · Recibir y verificar

Crea C:\RackClick-Instalar16 mediante Explorador → Este equipo → Disco local(C:) → Nuevo → Carpeta. Copia el ZIP y abre Inicio → Windows PowerShell → clic derecho → Ejecutar como administrador. Comprueba su SHA256 con el valor entregado por el coordinador por separado.

Get-FileHash -LiteralPath 'C:\RackClick-Instalar16\RackClick-Servidor-16.zip' -Algorithm SHA256

02 · Extraer

Extrae en una carpeta nueva, sin mezclar ediciones. Detente si la carpeta de salida existe o el hash no coincide.

Expand-Archive -LiteralPath 'C:\RackClick-Instalar16\RackClick-Servidor-16.zip' -DestinationPath 'C:\RackClick-Instalar16\Extraido16'

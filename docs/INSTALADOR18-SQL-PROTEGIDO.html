RackClick18 · instalación nueva desde cero

Aplicación48, catálogo884 revisiones/877 modelos y MFA con gracia45 y exención del administrador global. Edición para ensayo y revisión de Wascar. No cambia D ni otra instalación. No es actualización automática ni adopción productiva.

00 · Preparar Windows

  1. Usa otra VM Windows Server2025 de64bits con interfaz gráfica, sin rol de controlador de dominio. Termina Windows y VMware Tools. Conserva un snapshot limpio desde VMware.
  2. Deja la tarjeta conectada a la red desde la que accederás. La IP prevista debe estar asignada y ser estable (reserva DHCP o configuración de red gestionada por ti). El instalador no configura IP/DNS de Windows.
  3. Inicia sesión con una cuenta Windows administradora. No crees cuentas RackClick ni instales PostgreSQL, SDK, Node o Python previamente: el paquete incluye los componentes necesarios.

01 · Copiar y verificar

  1. Crea en Explorador la carpeta C:\RackClick_Instalar18. Copia allí el ZIP de entrega y el registro externo de SHA256 facilitado por Codex.
  2. Abre Inicio, escribe Windows PowerShell, pulsa con el botón derecho y elige Ejecutar como administrador; confirma UAC. Comprueba el ZIP antes de extraer. Sustituye el nombre si has recibido el paquete completo en lugar del envoltorio.
Get-FileHash -Algorithm SHA256 -LiteralPath 'C:\RackClick_Instalar18\RackClick-Servidor-18.zip'

El hash debe coincidir exactamente con el registro externo de entrega. Si difiere, detente. El hash del propio ZIP no puede incluirse dentro de sí mismo. No uses hashes de ediciones anteriores.

Expand-Archive -LiteralPath 'C:\RackClick_Instalar18\RackClick-Servidor-18.zip' -DestinationPath 'C:\RackClick_Instalar18\Extraido18'

En el paquete completo, abre su carpeta principal y utiliza 01-INSTALAR.cmd. Si utilizas sólo el envoltorio, ejecuta:

powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File 'C:\RackClick_Instalar18\Extraido18\RackClick-Servidor-18\INICIAR.ps1'

02 · Revisar los campos del asistente

  1. IP de escucha: la dirección actual de esta VM nueva. Nombre DNS/IP del navegador: el nombre o IP por el que abrirás RackClick. No reutilices la IP de D si otra VM la tiene.
  2. HTTPS: 5443. PostgreSQL local: 55441. Deben estar libres. PostgreSQL sólo escucha localmente; no abras su puerto en la red.
  3. Red autorizada: la subred real, por ejemplo 192.168.206.0/24 sólo si corresponde a tu red. El cortafuegos limita el acceso HTTPS a ella.
  4. Systemhaus: el nombre deseado. Administrador de RackClick: Wascar u otro nombre propio. Esta cuenta pertenece a RackClick; es distinta de tu administrador de Windows.
  5. Servicio y cuenta Windows: utiliza los nombres propuestos para esta instalación nueva. El asistente genera credenciales nuevas de servicio y PostgreSQL y protege sus archivos.
  6. Modo: New. Deja vacíos los campos de Restore. Confianza de CA: autoriza la CA local en este servidor para verificar HTTPS; en otro PC se importa sólo el certificado público de la CA.
  7. Pulsa Revisar e instalar. No vuelvas a pulsarlo mientras trabaja. VisualC++ puede requerir reiniciar: si lo indica, conserva el informe, reinicia y sigue su instrucción antes de otro intento.

03 · Primer acceso y reinicio

  1. Espera el resultado de HTTPS y backup. Pulsa Acceso privado para ver tus credenciales en la VM; no las envíes por chat. Abrir RackClick abre la URL indicada.
  2. Cuando indique awaiting_reboot, reinicia Windows desde Inicio→Encendido→Reiniciar. No reviertas el snapshot.
  3. Tras volver al Escritorio, abre el acceso RackClick-VERIFICAR-18-… creado por esta edición y pulsa Verificar instalacion. Exige postboot_verified antes de considerar comprobado el arranque automático.
  4. Activa tu MFA desde el panel de cuenta cuando quieras. Usuarios/técnicos/administradores de clientes tienen45días; el global está exento y puede activarlo para sí. No desactives tu MFA para cargar Demo50.

04 · Cargar los50 clientes

  1. En una instalación nueva y aún sin clientes, abre la carpeta CARGAR-50-CLIENTES del paquete completo o del ZIP Demo50 trilingüe03. Ejecuta su CMD y lee su LEEME.
  2. Indica la URL HTTPS de esta VM, tu usuario y contraseña de RackClick de forma privada. Si tienes MFA, introduce tu código sólo en esa consola. El cargador verifica permisos globales y que el servidor48 esté vacío.
  3. Confirma una sola carga. Espera: son2553comandos y20665puertos. Si hay un rechazo o resultado incierto, conserva la salida y no repitas automáticamente ni borres datos.
  4. Resultado esperado: demo50_loaded_verified,50clientes,180racks,1563equipos,20665puertos y2207conexiones. Los17nombresEN,17DE y16ES se mantienen al cambiar idioma. Los inventarios conservan su topología y atributos originales.
  5. Recarga el navegador, revisa clientes en los tres idiomas de interfaz y crea una copia nueva desde el panel administrativo. El ZIP Demo50 no contiene usuarios ni MFA históricos.

05 · Si algo falla

No borres carpetas, cuentas ni bases. Conserva el informe automático del Escritorio y usa RECOPILAR-INFORME si hace falta. Comparte sólo el ZIP sanitizado, nunca Acceso privado, archivos de claves ni contraseñas. Un fallo no autoriza reinstalar sobre D/E ni repetir una carga parcial.

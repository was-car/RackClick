## Decisiones sobre herencia

RC9 aporta UI, estilos, iconos, recursos locales, fixtures, informes y reglas funcionales. R3 aporta contratos probados de importación atómica, aislamiento, idempotencia y revocación de permisos como casos a portar. El frontend simplificado R3 y su servidor HTTP Python no se convierten en el producto definitivo. Los datos R3 no son prerrequisito: la instalación limpia está autorizada.

El paquete no incluye datos reales ni contraseñas del ZIP recibido. El directorio `reference/r3` mantiene sus propios documentos históricos; el contrato S0 determina la dirección nueva.

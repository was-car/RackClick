Instalar RackClick desde cero y cargar50clientes

Entrega18 · aplicación48 · Windows Server2025x64 · EN/DE/ES. Sigue los pasos en esta VM nueva. Conserva D y E.

00 · Windows y snapshot

  1. Termina la instalación de Windows Server2025 con Escritorio y VMware Tools. El servidor no debe ser controlador de dominio.
  2. Desde VMware conserva un snapshot limpio. Inicia sesión en Windows como administrador. No crees cuentas RackClick ni instales PostgreSQL, SDK, Node o Python: vienen incluidos los componentes de ejecución.
  3. Conecta la VM a tu red. Necesitas su IP asignada, el nombre/IP que usarás en el navegador y la subred autorizada. El asistente los propone para revisarlos; no modifica IP/DNS de Windows.

01 · Crear carpeta y copiar el ZIP

  1. En la VM abre Explorador→Este equipo→DiscoC:. Crea una carpeta llamada RackClick_Instalar18.
  2. Copia allí RackClick-Windows-Completo-18.zip. El ZIP incluye instalador, runtime, PostgreSQL, catálogo, manual y cargador de los50clientes.
  3. Recibe también de Codex el SHA256 externo de esta entrega. No uses el de otra edición.

02 · Abrir PowerShell como administrador y verificar

Abre Inicio, escribe Windows PowerShell, botón derecho→Ejecutar como administrador. Confirma UAC. Copia esta línea:

Get-FileHash -Algorithm SHA256 -LiteralPath 'C:\RackClick_Instalar18\RackClick-Windows-Completo-18.zip'

Compara los64caracteres con el registro externo. Si no coinciden, detente sin extraer ni ejecutar.

03 · Extraer y abrir el instalador

En esa misma PowerShell ejecuta, una vez y en este orden:

Expand-Archive -LiteralPath 'C:\RackClick_Instalar18\RackClick-Windows-Completo-18.zip' -DestinationPath 'C:\RackClick_Instalar18\Extraido18'

powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File 'C:\RackClick_Instalar18\Extraido18\RackClick-Windows-Completo-18\01-INSTALAR-NUEVO.ps1'

Si Extraido18 ya existe, conserva su contenido y usa otra carpeta nueva en ambos comandos. Si se detecta un servicio RackClick previo, se detiene: usa el servidor limpio previsto. No borres otra instalación.

04 · Completar el formulario

  1. IP de escucha: la IP actual de esta VM. DNS/IP navegador: el nombre o IP que usarás para abrirla. Cada VM debe tener su propia IP.
  2. HTTPS5443 y PostgreSQL local55441, libres. PostgreSQL queda limitado al equipo; no abras su puerto en la red.
  3. Red autorizada: tu subred real, escrita en forma canónica, por ejemplo192.168.206.0/24 sólo si ésa es tu red.
  4. Systemhaus: tu organización. Administrador RackClick: Wascar u otro nombre que prefieras. No es la contraseña de Windows.
  5. Deja los nombres propuestos de servicio y cuenta estándar. El asistente genera cuentas y claves nuevas. ModoNew, campos de Restore vacíos.
  6. Autoriza la confianza de la CA local en este servidor y pulsa Revisar e instalar. Espera sin repetir. Si VisualC++ pide reinicio, sigue ese mensaje y conserva el informe.

05 · Acceso y reinicio

  1. Cuando confirme HTTPS y backup, abre Acceso privado para ver tus credenciales en la VM y Abrir RackClick para entrar. No envíes claves por chat.
  2. Cuando aparezca awaiting_reboot, reinicia Windows desde Inicio→Encendido→Reiniciar. No reviertas el snapshot.
  3. Al volver al Escritorio, abre RackClick-VERIFICAR-18-… y pulsa Verificar instalacion. El resultado esperado es postboot_verified.

06 · Cargar los50clientes sintéticos

Sobre esta instalación48 nueva, aún sin clientes, abre esta carpeta:

C:\RackClick_Instalar18\Extraido18\RackClick-Windows-Completo-18\CARGAR-50-CLIENTES
  1. Haz doble clic en CARGAR-50-CLIENTES.cmd. Introduce la URL HTTPS mostrada por la instalación, tu usuario y contraseña de RackClick en esa consola. Si tu cuenta tiene MFA, introduce allí tu código. No desactives el factor para cargar datos.
  2. Lee el resumen y confirma una sola carga. Son2553comandos: espera mientras trabaja. El cargador exige permiso global y servidor vacío, compara las ocho colecciones y no reintenta automáticamente.
  3. Resultado esperado: demo50_loaded_verified;50clientes,66sitios,88edificios,226salas,180racks,1563equipos,20665puertos y2207conexiones.
  4. Si hay un fallo o resultado incierto, conserva la salida y detente: no repitas, no borres y no ejecutes limpieza.

07 · Comprobar y guardar

  1. Recarga RackClick. Verifica clientes como Oakbridge Office Supplies, Lindenwerk Büroservice y Papelería Encinar. Hay17empresasEN,17DE y16ES.
  2. Cambia el idioma de interfaz entre EN, DE y ES. Los nombres propios no se traducen. Entra en un cliente, sitio, sala y rack para ver equipos y conexiones.
  3. Activa tu MFA desde la cuenta cuando quieras. Rige gracia45días para usuarios/técnicos/administradores de clientes y exención del global; no se reinicia el plazo al desactivar un factor.
  4. Desde el panel administrativo genera una copia nueva con los datos cargados y conserva su recibo. El ZIP Demo50 es inventario sin usuarios/factores históricos; no sustituye un backup completo del servidor.
  5. Conserva informes sanitizados, copia y snapshot según tu operación. La aceptación final del servidor es de Wascar.

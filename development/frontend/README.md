No se monta la aplicación offline ni su autosave.

Solo preferencias de idioma/tema se guardan en localStorage. Credenciales, sesión CSRF y datos compartidos no se guardan allí. El servidor autoriza toda operación. Los controles reflejan capacidades de `/api/v1/me`; no son una frontera de seguridad.
